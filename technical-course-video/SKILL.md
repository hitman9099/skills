# 技术微课制作

先确认交付物：新整片、指定镜头、旁白字幕，或格式转换。继续既有项目时，以**用户实际审阅的最新成片**、分镜清单和配音时间戳为基准。把成片时间点换算成镜号和镜内时间，再修改。收集本次的分辨率、帧率、旁白音色、保留内容及禁止出现的元素。项目路径、章节数、飞机型号、工具与声线由当次任务决定。

## 从讲稿到成片

1. **整理分镜。** 每镜写明镜号、教学点、精确旁白、对应的动作和出现时机、相机、标注、时长/帧数、素材来源及验收条件。区分用户要求和附件中的素材内容。技术事实有疑问时先查可靠资料，把教学示意与实测或仿真数据说清。参照 [分镜与修订示例](references/storyboard.md)。
2. **选择能控制画面的办法。** 固定机构、精确转轴、部件识别和连续姿态优先用可编辑的三维模型或矢量动画。Blender 适合刚体、相机和受力示意。ComfyUI 可提供静态参考图、背景或其他允许随机变化的素材。已有合格素材可复用。读 [三维和标注做法](references/animation.md)。
3. **先做关键镜。** 抽取有风险的动作、最容易被挡住的标注和一段新声音，产出可检查的短片或首/中/末帧。用画面检查部件、方向和可读性，用对象矩阵、转轴位置和局部坐标检查刚体。修正后继续完成已授权的制作。若只改若干镜，复用可用的其余片段并单独输出新版本。
4. **按声音安排动作。** 有全片配音就先做音视频对应检查；只有音色样本时，用用户指定音色重新生成所需台词并记录来源。按每句实际语音开始、结束来排字幕、高亮、箭头、公式或相机动作。检查解说换了教学点时画面有相应变化。读 [旁白和成片](references/postproduction.md)。
5. **合成和验收。** 以帧为统一时基。字幕、图例和章节标题用独立图层排版，检查全段遮挡。先合一条连续旁白，再与视频封装；拼接仅视频流，避免逐镜 AAC 的编码延迟累加。检查首尾帧、切点、分辨率、固定帧率、字幕和音轨，复核用户指定时间段。交付 MP4 的实际路径、规格、主要修订及局限。

## 随包工具

- [课程清单模板](assets/course.json) 可复制到项目根目录，填写每镜的源画面、旁白和字幕时间。
- [合片脚本](scripts/course_video.py) 用 Python 标准库及 FFmpeg 完成画面尺寸/帧率统一、中文底部字幕、顶部章节标题、连续旁白和逐帧核验。命令见 [旁白和成片](references/postproduction.md)。
- 换电脑时先定位 Blender、Python、FFmpeg 和可显示中文的字体，检查源素材及输出盘。工具路径可传参；优先复用本机可用工具，有需要再按项目安装。使用语音合成时，准备相应模型及运行环境。
