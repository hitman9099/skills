# 技术微课制作

先确定交付范围和规格。返修以用户实际审阅的最新成片和对应工程为基准，通过截图的章节、字幕和构图，或用户给出的时间点，定位到镜号、镜内帧及源文件。截图可能来自同一资产的另一个镜头。参照 [分镜与返修](references/storyboard.md)。

1. **拆分讲解。** 每镜记录教学点、准确台词、动作起止、相机、标注和验收条件。用实际语音的时间安排动作与高亮。
2. **选画面做法。** 精确几何、固定铰链和连续刚体运动优先用可编辑的三维模型或矢量动画。参考图用于校正可见外形。若用 ComfyUI，选择允许随机变化的静图或背景。读 [三维、动作与标注](references/animation.md)。
3. **先核对风险较高的画面。** 看同角度的首、中、末帧，核对转轴、受力方向、标注是否到位及挡住了什么。对于可复用的模型和辅助物，排查实际参与合片的各镜实例。保留用户之前验收的修订。
4. **按问题的范围修改。** 几何改源模型，发音改对应的词或短句。局部返修先确定镜长和片段边界，再复用已验收的镜头和音轨。读 [旁白、合片与验收](references/postproduction.md)。
5. **核验实际交付文件。** 逐帧核对尺寸、帧数和时间戳，检查音轨、字幕和修订位置。交付 MP4、规格和可定位的修订抽帧。区分原生渲染尺寸、合片输出尺寸和转帧方式。

## 随包工具

- [课程清单模板](assets/course.json) 和 [合片脚本](scripts/course_video.py) 用于把已有画面、连续旁白、中文字幕和章节标题编成 MP4，并核验时间轴。
- [Blender 场景扫描脚本](scripts/audit_blender_objects.py) 按对象名称和类型检查各镜的实际源场景，可用已修订场景覆盖同名旧镜头。命令见 [三维、动作与标注](references/animation.md)。
- 换电脑时定位 Blender、Python、FFmpeg 和中文字体，按项目迁移分镜、源素材和当前验收成片。使用语音合成时另准备授权音色和模型环境。
