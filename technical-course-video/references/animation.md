# 三维、运动与标注

将不动部件挂到整机根节点。每个舵面和关节独立建模，把铰链设在作用位置、用局部旋转动画。镜头移动由相机完成；整机姿态变化由统一根节点完成。记录坐标定义、观察方向和正负角的实义。先用正视、俯视、侧视确认左右及前后，再选教学镜头。

航空案例的检查可按新素材调整：

- 机头至机尾为纵向，机体左右为横向，向上是立向。左右标签按飞机自身左右。迎面来流箭头指向从机头到机尾。全动鸭翼绕固定横向轴转动，前缘抬升时后缘降低；主翼前缘的小翼面、后缘副翼和腹鳍按参考分别核对。
- 固定相机时叠合首末帧检查固定部分；转动整机时比较 `root.matrix_world.inverted() @ object.matrix_world`。对铰链比对根节点坐标中的轴方向和轴点，检查是否脱离机身、动作的正负方向和停止位置。用逐帧数值检查补足首尾图。
- 相对来流方向与翼弦夹角用侧视图表达，弧线跟随关键帧，按要求放在前缘侧。力箭头连到作用点，重量方向按世界坐标向下。坐标轴、尺寸符号和公式按当前讲稿显示。
- 定性流线可用曲线配下游粒子。明确来流、起点、下游方向和涡包络变化；粒子循环时在路径端部淡出和重生。分离到低头的镜头用可见事件及停留表达趋势，避免暗示精确规律或自动恢复。

先在本机渲一帧，确认设备及降噪实际运行并估算耗时。H100 项目验证过 CUDA 加 GPU 降噪可加速；换设备或 Blender 版本先探测支持，也可以用 CPU。保持同一镜头的色彩管理和光线。像素确实相同的保持帧可以复用。长镜头保留编号序列便于补帧和重编码。

字幕、章节、公式和测量标注使用独立图层。细线可先在更高分辨率绘制再缩小抗锯齿；标签和距离线端点可以由 Blender 相机投影得到。章节标签用统一上角位置，扫描整段冲突。有遮挡时换到另一处共同安全位置或调整构图。用最终输出尺寸检查中文字、细线和遮挡。
