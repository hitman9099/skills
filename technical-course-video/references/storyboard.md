# 分镜与返修

用稳定镜号关联讲稿、模型、导出视频和旁白 WAV。以帧数确定镜长，整片时间轴用 `[首帧, 尾帧)`。一镜记录一个主要因果或一组连贯动作。写清部件、转轴、观察方向、动作起止、相机、标注和画面验收条件。提到多个部件时，从实际旁白取词级时间来切换高亮。

| 旁白提示 | 同步的画面事件 | 验收 |
| --- | --- | --- |
| 鸭翼在前，三角主翼在后 | 分别在两个名称说到时高亮对应翼面。 | 构型对比和特写都使用当前模型版本。 |
| 前缘涡随来流向后发展 | 从前翼附近显露细涡，随后增加向后的长度与半径。 | 能看到逐步形成的过程，流向向后。 |
| 方向舵偏转，使垂尾产生侧力，改变机头朝向 | 先从后方看舵面偏转及侧力，再在相机固定的片段看整机转向。 | 铰链固定，舵面、尾部受力与机头方向互相对应。 |

## 已有成片的返修

1. **确认版本与镜头。** 用当前成片截出用户所指画面，结合章节名、字幕、对比构图和部件高亮识别镜号。没有时间码时也要实测。相似构图可能来自特写、对比、片头或小结，逐一确认实际来源。
2. **建立换镜表。** 记录每个受影响镜的全片首尾帧、镜长、活动源场景、引用资产、修改项和验收帧。同名镜头若有多轮修订，按最终合片实际用到的文件排序。检查共用模型、复制出来的对比飞机以及复用镜头的小结画面。
3. **按层归因。** 区分源几何、可渲染辅助对象、绑定位姿、烘焙纹理和后期标注。修掉一次瑕疵后，查同一来源在其他镜头里的实例。移除可见转轴辅助线时保留实际绑定，并检查转动姿态。
4. **验证修改的影响。** 对照同一时间和同一角度的修前、修后帧。涉及转动至少看起始、中间和停止姿态。单改画面时复用原镜长。若镜长必须改，重算后续字幕、章节和音频偏移。续渲前核对缓存的镜号、场景版本、尺寸和帧率。

“某段太静”可将接触、分离、受力、姿态或标注变更与讲解绑定。小结有分条旁白时，可让条目逐个出现并同步切换配图或动画。保留能帮助理解的停顿。
