# 三维技术微课制作 · technical-course-video

## 这个技能做什么

根据讲稿、参考图或模型、旁白音频，制作技术微课和工程原理讲解视频。也可以提供已有成片和截图，局部修订模型、动作、标注、字幕或旁白发音。

1. **拆分镜、定时间。** 记录每镜的教学点、台词、动作、标注和验收条件，先做关键动作样片。
2. **制作或修订镜头。** 将机构运动、箭头、公式和部件高亮安排到对应的解说时点。返修时从当前成片定位镜号和时间，扫查所有引用同一模型的镜头，再复用已验收的片段。
3. **合成并核验。** 按分镜清单合并画面、旁白、中文字幕和章节标题，生成指定分辨率与帧率的 MP4。随包合片脚本核对帧数、逐帧时间戳和音频长度。要求原生 4K 时，也检查三维源渲染的像素尺寸。

## 安装

- **Codex**：在对话中输入 `$skill-installer https://github.com/hitman9099/skills/tree/main/technical-course-video`。安装后在新对话中用 `$technical-course-video` 调用。
- **手动安装**：克隆 [本仓库](https://github.com/hitman9099/skills) 或下载其 ZIP，把完整的 `technical-course-video` 文件夹复制到本机智能体扫描的技能目录。Codex 可使用个人目录 `~/.agents/skills/` 或项目的 `.agents/skills/`。使用其他智能体时，按其安装约定保留目录内的相对路径。
- **临时加载**：让智能体先读 [SKILL.md](SKILL.md)，再按任务读取其中链接的参考文件、模板和脚本。

## 调用示例

```text
用 $technical-course-video，根据我提供的讲稿和参考图制作工程原理微课。
先做关键动作样片，再制作整片。让画面变化跟随旁白，交付 2560×1440、30 fps 的 MP4。
```

返修时也可以直接贴截图，附上用户实际审阅的 MP4 和对应的 Blender 工程。

```text
用 $technical-course-video，定位截图中机身附近的多余辅助线。
扫描共用这一模型的其他镜头，修复实际受影响的镜头，交付原生 4K、30 fps 成片和带时间点的前后对照。
```

## 涉及哪些工具

| 工具 | 做什么 | 什么时候需要 |
| --- | --- | --- |
| Codex 或兼容的智能体 | 读取技能，按项目素材和交付要求执行流程。 | 加载和使用本技能时。 |
| Python 3.9+ | 读取课程清单、组织镜头和旁白、运行随包脚本。脚本只用 Python 标准库。 | 使用随包合片脚本时。 |
| FFmpeg（含 `libx264`、`libass`） | 统一分辨率和帧率、烧录字幕与章节标题、封装 MP4、解码核验。 | 使用随包合片脚本时。 |
| 本机中文字体 | 渲染中文字幕和章节标题。 | 需要在画面上排中文时。 |
| Blender | 建模、设置固定转轴和刚体关键帧、安排相机、渲染新镜头。可按设备使用 CPU 或 GPU。也可运行随包只读脚本，按名称排查镜头里的对象。 | 新制、重渲或检查三维场景时。 |
| ComfyUI | 生成参考图或背景等允许随机变化的素材。 | 需要生成这类素材时可选。 |
| IndexTTS2 或其他语音工具 | 根据授权音色参考生成新台词。 | 需要重新合成旁白时可选，也可使用真人录音。 |
| Whisper 等语音识别工具 | 提取实际发音时间，辅助对齐字幕和动作，专有名词由原稿和复听核对。 | 缺少可靠的旁白时间戳时可选。 |

用已有镜头进行后期合片时，准备 Python、FFmpeg 和所需字体即可。工具可使用本机安装版或便携版。先用脚本的 `doctor` 命令检查 FFmpeg 能力，再按 [合片脚本说明](references/postproduction.md) 使用 [课程清单模板](assets/course.json)。扫描 Blender 场景的方法见 [三维、动作与标注](references/animation.md)。

继续同一个项目时，随技能一起迁移分镜、源模型、旁白、字幕、参考素材和当前成片。制作新项目时，从新讲稿和素材开始填写清单。
